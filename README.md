# Юнитка

Автономный калькулятор юнит-экономики. Все расчёты и экспорт прогноза выполняются в браузере — серверный API и ChatGPT не требуются.

## Локальная разработка в PyCharm

Требуется Node.js 22 или новее.

1. Откройте эту папку через **File → Open**.
2. В **Settings → Languages & Frameworks → JavaScript Runtime** выберите Node.js 22.
3. Откройте встроенный терминал PyCharm и выполните:

```bash
npm ci
npm run dev
```

4. Откройте `http://localhost:3000`.

Основная логика находится в `app/page.tsx`, оформление — в `app/globals.css`, изображения — в `public/`.

## Структура проекта

- `app/` — интерфейс, расчёты и стили;
- `public/` — логотип и статические файлы;
- `.github/workflows/` — автоматическая публикация в GitHub Pages;
- `Dockerfile`, `compose.yml`, `nginx.conf` — необязательный запуск на собственном сервере.

## Проверка production-сборки

```bash
npm run build
```

Готовый статический сайт появится в каталоге `out/`.

## Публикация

После отправки изменений в ветку `main` GitHub Actions автоматически собирает сайт и публикует его в GitHub Pages:

```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

В репозитории GitHub один раз выберите **Settings → Pages → Source → GitHub Actions**.

Для собственного поддомена укажите его в поле **Custom domain** на странице Pages и добавьте выданную GitHub запись `CNAME` в DNS домена.

## Автономность

Сайт не использует базы данных, внешние API или сервисы ChatGPT. Экспорт прогноза открывает стандартное окно печати браузера, где отчёт можно сохранить в PDF.
